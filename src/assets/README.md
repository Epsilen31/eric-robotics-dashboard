Angular serves this directory at `/assets/`. Both files are bundled locally so playback and map loading require no external service.

- `video/feed.mp4`: Sintel trailer sample from the [Three.js video demo](https://threejs.org/examples/webgl_materials_video.html), downloaded from [this MP4](https://threejs.org/examples/textures/sintel.mp4). Sintel is a Blender Foundation production, licensed under [Creative Commons Attribution 3.0](https://durian.blender.org/sharing/). This is a demonstration video, not a live robot feed.
- `map/map.pcd`: [office1.pcd](https://github.com/PointCloudLibrary/pcl/blob/master/test/office1.pcd) from the Point Cloud Library test data. See the [PCL license](https://github.com/PointCloudLibrary/pcl/blob/master/LICENSE.txt); a copy is included at `map/PCL-LICENSE.txt`. Invalid coordinates were removed, and XYZ was converted to `(x, z, -y)` so the scan uses Z as height. The result contains 254,456 points in binary PCD format. This is an independent sample scan, not synchronized with the video.

Replace these files with your own MP4 (H.264) and PCD to use robot recordings. Keep the filenames unchanged, or update the component URLs. The map assumes Z coordinates represent height.

- `map/floor-plan.svg`: locally authored, illustrative facility floor plan with labelled areas and a demo robot marker. This is not derived from `map.pcd` and is not a live survey. The sidebar **3D Map View** action shows the original PCL sample. The moving robot, goal marker and route are drawn separately by Angular.

- `ros-config.json`: default local bridge/topic configuration; no credentials. The bridge is optional and is connected explicitly from settings.
- Synthetic ROS cloud and camera: generated by `tools/mock-ros.cjs`, independently of the PCL scan, SVG facility and MP4. The mock PNG is created in code and has no third-party image source.
